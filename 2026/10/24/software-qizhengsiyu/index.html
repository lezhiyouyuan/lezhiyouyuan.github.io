七政四余排盘软件整理：Windows、macOS、iOS、Android

2026-10-24
#七政四余 #星学

1. 简介

七政四余是中国传统星命术，以日月、金木水火土「七政」及罗睺、计都、紫炁、月孛「四余」为核心，结合十二宫、二十八宿等，推演人事吉凶。

2. 常用排盘软件

按平台整理常见的软件和在线工具：

2.1 Moira

平台：Windows

Moira 是七政四余领域影响最大的早期软件之一，也是目前研究传统七政四余软件时很难绕开的经典工具。

Moira 1.50 内置 Swiss Ephemeris，支持约公元前 5400 年至公元 5400 年，并陆续加入了古宿制、郑氏星案宿制、恒星制、回归制、罗计方向、真太阳时、五星迟留伏逆等大量设置。

链接：

  • 七政四餘星盤 天星擇日 占星盤 - Moira
  • Moira 历史版本

评价：经典、专业、历史影响大。

2.2 七政四餘排盤 App

平台：iPhone / iPad / macOS

这是 App Store 上比较直接的七政四余专用 App。macOS 也可以运行 iOS / iPadOS 版本。

软件集中于七政四余本身，并加入了星历、日月食、传统历法等功能。

链接：

  • App Store：七政四餘排盤

评价：目前 Apple 平台比较纯粹的七政四余专用选择之一。

2.3 爱占星 Love Astrology

平台：iOS / iPadOS / Android / Web

爱占星最初以西方占星为主，现已发展为综合占星平台，正式支持：西方占星、印度占星、八字、紫微斗数、七政四余等。

官网已经把七政四余列为正式排盘体系，并设有独立的七政四余知识文档。

链接：

  • 爱占星官网
  • 爱占星网页版
  • 爱占星七政四余知识库
  • 东方术数文档
  • App Store：爱占星

评价：目前手机端最方便的综合型七政四余工具之一。

2.4 Guolaoxing《果老星宗》排盘软件

平台：Windows / Android

这是仍在维护的专业七政四余桌面软件之一，同时包含果老星宗、天星择日、风水、六壬、河洛理数、万年历等功能。

网站同时提供 Windows 软件和 Android App 下载页面。

链接：

  • Guolaoxing 官网
  • Windows 软件 / Android App 下载中心

评价：专业程度高，适合果老派使用者。

2.5 天官手记 TIANGUAN

平台：Windows / macOS / Android / Web

天官手记是比较完整的跨平台七政四余工具。相比传统 Windows 单机软件，优势是跨平台。

其特点是支持多种盘制，可以处理黄道、赤道、恒星、回归以及不同宿制，并加入本命、流年、神煞、化曜等七政四余常用内容。

链接：

  • 天官手记官网
  • 七政四余 MCP / API 项目

评价：目前跨平台能力较强，尤其适合 macOS、Android 用户，也适合比较不同盘制。

2.6 张果观象

平台：Web 浏览器

张果观象是近年出现的七政四余数字化平台。

2026 年版本已经加入五星迟、伏、留、逆、速状态、流年神煞、喜忌理法等内容，排盘年代范围已经扩展至公元 0—3000 年。

链接：

  • 张果观象官网 / Web 排盘

评价：现代化程度较高，适合日常排盘、流年查看和案例管理。

2.7 知命网七政四余

平台：Web，Windows / macOS / iOS / Android 均可

知命网的特点是明确区分不同历史阶段的七政四余盘式。

链接：

  • 知命网七政四余在线排盘
  • 知命网首页

评价：研究古法星制有价值。

2.8 ziwei.biz 七政四余

平台：Web

这是一个明显偏向算法透明的在线七政四余工具。

适合拿来核对不同软件为什么出现不同结果。

链接：

  • ziwei.biz 七政四余在线排盘
  • ziwei.biz 主站

评价：适合研究排盘算法和不同口径，参数透明、方便核验。

2.9 星阙 Horosa

平台：Windows

Horosa 是一套综合玄学与占星工作站，包含西方占星、印度占星、八字、紫微、奇门、六壬以及七政四余。

链接：

  • Horosa Windows GitHub
  • Horosa 完整功能说明 README
  • Horosa Releases / 安装包

评价：功能非常丰富，适合研究型用户。

2.10 衍象坊·真天象星命台

平台：Web

衍象坊的七政四余工具明显偏技术研究。

支持：七政四余星历表；CSV / JSON 导出；五星速度；顺逆；三方四正；流年；SVG / PNG 星盘导出等。

链接：

  • 衍象坊·真天象星命台
  • 衍象坊主站

评价：偏技术研究型，算法说明和数据导出功能有价值。

如果需要进一步用 Python 或 Excel 处理七政四余星历，它比普通排盘网站更实用。

3. 总结

七政四余软件重要的是：采用什么盘制、什么宿制，以及罗、计、炁、孛究竟如何计算等。
