目前常见的七政四余排盘软件整理

七政四余排盘软件并不算多，而且不同软件在黄道/赤道、恒星制/回归制、二十八宿距星、罗计、紫炁、月孛等算法上可能存在明显差异。

因此，研究七政四余时不能只看“盘面是否漂亮”，还应注意软件采用的具体星制与算法。

下面按平台整理目前较常见的软件和在线工具。

1. Moira

平台：Windows

Moira 是七政四余领域影响最大的一批早期软件之一，也是目前研究传统七政四余软件时很难绕开的经典工具。

现存最终版资料显示，Moira 1.50 内置 Swiss Ephemeris，支持约公元前 5400 年至公元 5400 年，并陆续加入了古宿制、郑氏星案宿制、恒星制、回归制、罗计方向、真太阳时、五星迟留伏逆等大量设置。

目前常用的是网友从原安装包整理出来的 Windows 绿色版；原程序基于 JRE 7 Windows x86。

链接：

  • Moira GitHub 绿色版
  • Moira README / 安装说明
  • Moira 历史版本修改记录

评价：经典、专业、历史影响大，但软件已经明显老旧。

如果研究不同七政四余星制、古宿制与现代软件之间的差别，Moira 至今仍具有很高的参考价值。

2. Guolaoxing《果老星宗》排盘软件

平台：Windows / Android

这是目前仍在维护的专业七政四余桌面软件之一，同时包含果老星宗、天星择日、风水、六壬、河洛理数、万年历等功能。

作者明确说明，七政四余部分因传承果老一派，采用黄道回归制，即今制。

网站同时提供 Windows 软件和 Android App 下载页面。

链接：

  • Guolaoxing 官网
  • 软件下载中心
  • 软件使用说明
  • Android App 下载页

评价：专业程度高，适合果老派、回归制使用者；缺点是体系取向明确，不适合拿来代表全部古法七政四余。

3. 爱占星 Love Astrology

平台：iOS / iPadOS / Android / Web

爱占星最初以西方占星为主，现已发展为综合占星平台，正式支持：

  • 西方占星
  • 印度占星
  • 八字
  • 紫微斗数
  • 七政四余等。

官网已经把七政四余列为正式排盘体系，并设有独立的七政四余知识文档。

网页版中也可以直接进入七政四余模块。

链接：

  • 爱占星官网
  • 爱占星网页版
  • 爱占星七政四余知识库
  • 东方术数文档
  • App Store：爱占星

评价：目前手机端最方便的综合型七政四余工具之一。

优点是可以在同一个软件中比较七政、西占、印占、八字、紫微等体系，日常排盘和案例管理尤其方便。

4. 天官手记 TIANGUAN

平台：Windows / macOS / Android / Web

天官手记是近年来比较完整的跨平台七政四余工具。

其特点是支持多种盘制，可以处理黄道、赤道、恒星、回归以及不同宿制，并加入本命、流年、神煞、化曜等七政四余常用内容。

相比传统 Windows 单机软件，它最大的优势是跨平台。

链接：

  • 天官手记官网
  • 天官在线入口
  • 七政四余 MCP / API 项目

评价：目前跨平台能力较强，尤其适合 macOS、Android 用户，也适合比较不同盘制。

如果需要进一步用 Python、AI 或批量程序处理七政四余数据，其 API / MCP 也很有价值。

5. 七政四餘排盤 App

平台：iPhone / iPad / Apple Silicon Mac

这是 App Store 上比较直接的七政四余专用 App。

相比爱占星这样的综合平台，它更加集中于七政四余本身，并加入了星历、日月食、传统历法等功能。

Apple Silicon Mac 也可以运行 iOS / iPadOS 版本。

链接：

  • App Store：七政四餘排盤
  • iPad 版本页面

评价：目前 Apple 平台比较纯粹的七政四余专用选择之一。

如果主要研究七政四余而不是综合占星，可以和爱占星配合使用。

6. 张果观象

平台：Web / 手机浏览器 / 电脑浏览器

张果观象是近年出现的七政四余数字化平台。

同一账户可以在电脑端与手机端通用，目前仍在持续更新。

2026 年版本已经加入五星迟、伏、留、逆、速状态、流年神煞、喜忌理法等内容，排盘年代范围已经扩展至公元 0—3000 年。

链接：

  • 张果观象官网 / Web 排盘

评价：现代化程度较高，适合日常排盘、流年查看和案例管理。

不需要安装传统桌面软件，是其明显优势。

7. 知命网七政四余

平台：Web，Windows / macOS / iOS / Android 均可

知命网的特点是明确区分不同历史阶段的七政四余盘式。

目前支持：

  1. 黄道恒星制——对应宋代《三辰通载》等体系；
  2. 赤道恒星制——对应元代《郑氏星案》；
  3. 似黄道恒星制——对应明代《果老星宗》。

网站同时列出黄道回归制，但目前标注为暂不支持。

链接：

  • 知命网七政四余在线排盘
  • 知命网首页

评价：研究古法星制非常有价值，尤其适合比较宋、元、明不同排盘口径。

如果研究《三辰通载》《郑氏星案》《果老星宗》之间的历史演变，这个工具很值得保留。

8. ziwei.biz 七政四余

平台：Web

这是一个明显偏向算法透明的在线七政四余工具。

它不仅给出星盘，还专门提供：

  • 立命设置
  • 真太阳时
  • 门派参考盘
  • 现代对照盘
  • 罗计
  • 月孛
  • 紫炁
  • 宿度等参数设置。

这类设计特别适合拿来核对不同软件为什么出现不同结果。

链接：

  • ziwei.biz 七政四余在线排盘
  • ziwei.biz 主站

评价：适合研究排盘算法和不同口径，优点是参数透明、方便核验。

对于研究“为什么 Moira、Guolaoxing、爱占星排出来不完全一样”，非常有参考意义。

9. 星阙 Horosa

平台：Windows

Horosa 是一套综合玄学与占星工作站，包含西方占星、印度占星、八字、紫微、奇门、六壬以及七政四余。

其七政模块支持：

  • 七政四余十一曜
  • 正恒星
  • 古法立成
  • 赤道回归
  • Horosa / Kinastro 双引擎
  • 罗计真、平交点
  • 月孛真、平远地点
  • 化曜
  • 庙旺
  • 洞微大限
  • 羽毛大限
  • 流年神煞等。

链接：

  • Horosa Windows GitHub
  • Horosa 完整功能说明 README
  • Horosa Releases / 安装包

评价：功能非常丰富，适合研究型用户。

如果只想简单排七政盘会显得庞杂；但如果希望比较七政、西占、印占、紫微等体系，它的优势很明显。

10. 衍象坊·真天象星命台

平台：Web

衍象坊的七政四余工具明显偏技术研究。

它采用现代天文算法直接计算七政位置，同时可以切换回归 / 恒星坐标、罗计约定、平 / 真交点等参数。

还支持：

  • 七政四余星历表；
  • CSV / JSON 导出；
  • 五星速度；
  • 顺逆；
  • 三方四正；
  • 流年；
  • SVG / PNG 星盘导出等。

链接：

  • 衍象坊·真天象星命台
  • 衍象坊主站

评价：偏技术研究型，算法说明和数据导出功能尤其有价值。

如果需要进一步用 Python 或 Excel 处理七政四余星历，它比普通排盘网站更实用。

11. qzpicker

平台：Android

qzpicker 是较早的 Android 七政四余 App。

项目说明明确指出，它实际上是对 Moira 的精简封装，主要保留七政四余静盘功能。

目前项目已经比较老，但源代码仍然公开，因此具有一定历史和算法参考价值。

链接：

  • qzpicker GitHub
  • qzpicker APK 直接下载
  • qzpicker 核心计算代码

评价：早期 Android 七政四余代表之一，现在更适合作为 Moira 系算法的历史参考。

12. 其他网页排盘

目前网络上还存在一些轻量级七政四余排盘网页。

这类工具最大的优势是：

无需安装，Windows、macOS、Linux、iPhone、Android 都可以直接使用。

但正式用于研究之前，应先确认网站是否公布：

  • 黄道还是赤道；
  • 恒星还是回归；
  • 二十八宿距星来源；
  • 罗计取法；
  • 月孛模型；
  • 紫炁算法。

算法不透明的网页工具，更适合临时排盘，不建议作为古籍命例复原和学术研究的唯一依据。

七政四余软件为什么会出现不同结果？

这是使用七政四余软件时最值得注意的问题。

即使输入完全相同的出生时间和地点，不同软件仍可能出现不同结果，主要来自以下因素：

1. 黄道还是赤道

《郑氏星案》等传统体系涉及赤道宿度，而现代软件大量使用黄道坐标。

2. 恒星制还是回归制

回归制以春分点为黄经 0°；恒星制则需要确定恒星基准。

两者受到岁差影响，年代越远差异通常越明显。

3. 二十八宿距星不同

不同软件可能使用：

  • 古代宿度表；
  • 郑氏星案古宿；
  • Moira 宿表；
  • 现代恒星位置；
  • 岁差校正后的宿界。

因此同一颗星的入宿度可能不同。

4. 罗睺、计都不同

需要确认：

  • 罗睺究竟对应哪一个交点；
  • 使用真交点还是平交点；
  • 罗计排列方向。

5. 月孛不同

月孛涉及月球远地点，不同程序可能采用：

  • 平远地点；
  • 真远地点；
  • 密切远地点；
  • 传统平均模型。

6. 紫炁不同

紫炁并非现代天文学中的实际天体，而是传统推算量。

不同软件采用的历元、周期和换算方法可能不同，因此软件间的紫炁位置尤其容易出现差别。

总结

目前较有代表性的七政四余工具，可以大致归纳为：

经典基准：Moira

果老回归今制：Guolaoxing

移动端综合工具：爱占星

Apple 专用七政：七政四餘排盤

跨平台工具：天官

现代网页平台：张果观象

古法星制研究：知命网

算法核验：ziwei.biz

综合研究工作站：Horosa

现代天文数据研究：衍象坊

真正研究七政四余时，最好不要只依赖一个软件。

比较理想的方式是：

Moira + Guolaoxing + 天官 / 爱占星 + ziwei.biz / 衍象坊

进行交叉验证。

七政四余软件真正重要的，不是盘面是否漂亮，而是先搞清楚：

它采用什么盘制、什么宿制，以及罗、计、炁、孛究竟如何计算。
